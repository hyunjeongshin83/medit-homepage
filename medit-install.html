PnP 설치 V1 · 샘플·매핑 단계

약사 면허를 확인한 뒤 받은 시리얼을 입력하면 설치 프로그램과 설치 방법 3가지(시리얼 · 링크 · Claude)가 나옵니다. 이 단계의 설치는 약국 프로그램의 표·열 이름을 확인해 연결 설정을 만드는 것까지이며, 환자 데이터는 읽거나 보내지 않습니다. 서버로 가는 정보의 전체 범위는 이 페이지 맨 아래에 적었습니다.

시리얼이 없다면 시범 이용 신청에서 요청해 주세요. 약사 면허를 확인한 뒤 발급합니다.

1. 설치 프로그램 받기

Python 3.8 이상이 있는 약국 PC(Windows·Mac)에서 쓰는 파일 하나입니다. 다른 프로그램은 설치하지 않습니다.

medit-pnp.py 받기

SHA-256 불러오는 중…

2. 명령 실행 (명령 프롬프트 또는 터미널)

Windows에서 python이 안 되면 py로 바꿔 입력하세요.

약사에게 보낼 링크

링크를 열면 이 시리얼이 입력된 화면이 열립니다. 약사 본인에게만 보내 주세요. 주소의 # 뒤는 서버로 전송되지 않으며, 열자마자 주소창에서 지워집니다.

링크로 연 뒤에는 같은 화면에서 "시리얼로 설치" 또는 "Claude로 설치"를 이어서 진행합니다.

Claude에 로그인해서 LLM으로 설치

Anthropic과 제휴·보증 관계가 없는 제3자 서비스 이용 안내입니다. Claude는 Anthropic의 서비스이며, MedIT은 Anthropic의 제휴사·보증을 받은 업체가 아닙니다.

  1. claude.ai에 로그인합니다. (명령을 직접 실행시키려면 Claude Code에 claude login으로 로그인)
  2. 아래 "안내문 복사"를 누르고, 새 대화에 붙여넣습니다.
  3. Claude가 명령을 안내하거나 실행하며 진행합니다. 구조 확인과 매핑 초안은 Claude가 돕습니다.
  4. 승인(approve)만은 약사가 직접 터미널에서 입력해야 합니다. 사람이 직접 입력하는 터미널이 아니면 프로그램이 거절합니다.

  • 시리얼: 확인·사용할 때 입력한 시리얼

설치 프로그램은 Windows의 설치 목록을 이 컴퓨터 안에서 읽고, 후보 이름과 일치한 것만 보냅니다. 환자 데이터 전송 기능은 업체 협약·약사 동의·개인정보 검토가 끝난 뒤 구현합니다. 문의는 시범 이용 신청으로 남겨 주세요.
